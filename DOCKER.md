# Docker packaging

Build the WAR and local Docker image with JDK 8:

```bash
export JAVA_HOME=/Library/Java/JavaVirtualMachines/jdk-1.8.jdk/Contents/Home
export PATH="$JAVA_HOME/bin:$PATH"
mvn -s settings.xml -pl platform -am -Pdocker-image verify
```

Start the web application and MariaDB:

```bash
BPMT_HTTP_PORT=18080 docker compose up -d
```

The Maven profile creates `platform/target/docker/`, copies `platform.war` and `ueditor.war` into it, then builds `riversoft-platform:3.4.1-SNAPSHOT`.

Runtime defaults are generated by `platform/src/main/docker/docker-entrypoint.sh`. The default database is `kyq`. Override defaults through Compose environment variables such as `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`, `JDBC_URL`, `HIBERNATE_AUTOUPDATE`, `SAFE_ADMIN`, and `JAVA_OPTS`.

MariaDB data remains under `./db/data`. The MariaDB service is configured with a larger packet limit so `db/kyq.sql.gz` can be restored without truncating large rows. The web container stores file uploads under `./runtime/files` and Tomcat logs under `./runtime/logs`.
